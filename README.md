# DevTrack Pro 🚀

A MERN-stack application for project management and developer tracking.

## 📌 About the Project

DevTrack Pro is a full-stack web application designed to help organize software projects and track development progress. The goal is to make project-related tasks and progress easier to manage in one place.

## 🎯 Objectives

- Organize software development projects.
- Track project progress and tasks.
- Build practical full-stack development experience.
- Explore features that can be extended in future versions.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Languages:** JavaScript

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- MongoDB
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/harshraj441/devtrack-pro.git
   ```

2. Navigate into the project:

   ```bash
   cd devtrack-pro
   ```

3. Install dependencies in the client and server directories:

   ```bash
   cd client
   npm install
   ```

   ```bash
   cd ../server
   npm install
   ```

4. Configure the required environment variables according to your project setup.

5. Start the frontend and backend using the scripts defined in their respective `package.json` files.
